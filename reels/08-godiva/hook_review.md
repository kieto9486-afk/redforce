## 1. 기존 후보 검토

### 7번 ⭐ 한정선 다음은 고디바, 그다음은? / 다음에 줄 설 디저트, 공식이 있어요

| 항목 | 평가 | 근거 |
|---|---|---|
| 1~3초 멈춤 | △ | 상단도 질문, 중앙도 약속이라 첫 화면에 **확인할 수 있는 사실이 0개**. "공식이 있어요"는 분석 계정 말투라 일반 시청자에겐 추상적 |
| 화제 키워드 | O | 한정선·고디바 두 검색어가 다 들어감. 잘된 고디바 영상 대부분이 한정선을 같이 부른 패턴과 일치 |
| 시의성 | △ | 고디바 아웃라이어가 9/29~10/13에 몰려 있음. 지금 고디바는 "다음"이 아니라 "이미 뜬 것". 그래서 "그다음은?"에 대한 답이 영상의 실제 가치가 됨 |
| 약속을 지킬 수 있나 | △ | "그다음은?"에 **구체적인 이름 하나**를 못 대면 "그래서 다음이 뭔데" 댓글이 달림. 구성안의 "찹쌀떡+하나"는 공식이지 이름이 아님 |
| 팔로우 이유 | O | "매주 먼저 알려 드릴게요"와 자연스럽게 연결 |

→ **상단 제목은 그대로 쓰고, 중앙 문구만 바꾸면 1순위**(아래 추천 1).

## 2. 추천 훅

### 추천 1 (1순위): 7번 + 확인된 충격 사실

- **상단 고정 제목:** 한정선 다음은 고디바, 그다음은?
- **화면 중앙(0~2초):** 8천원대 떡, 사다 주면 수고비 최대 7만 원
- **첫 화면:** 방향 문서의 세 칸 단면(한정선 / 고디바 / 물음표) 그대로. 고디바 칸 아래에 "수고비 최대 7만 원" 숫자 배지
- **첫 내레이션:** "8천 원대 떡 하나 사다 주면, 수고비가 최대 7만 원이었습니다."

| 항목 | 평가 | 근거 |
|---|---|---|
| 1~3초 멈춤 | O | 가격(8천원대)과 수고비(7만 원)의 대비가 소리 없이 바로 읽힘. "줄·돈" 욕구(10~41배 패턴) |
| 화제 키워드 | O | 상단에 한정선·고디바 |
| 사실 | O | 가격 7,500~9,000원(9월 말 현장 기준 보도), 수고비 개당 최대 7만 원(이코노미스트 10/17 원문) |
| 브랜드 '왜' 질문 위험 | O | 고디바가 왜 했냐가 아니라 시청자가 놀랄 사실이라 폐기 이유(회사 입장 질문)에 안 걸림 |
| 이어지는 흐름 | O | "이 정도로 줄이 생기는 디저트엔 공식이 있어요 → 그래서 그다음은?"으로 원래 45초 구성안에 그대로 붙음 |

**주의:** "최대"를 빼면 안 돼요. 그리고 지금은 예약제라 대리구매 시장이 식었을 수 있으니, 내레이션은 과거형("~였습니다")으로 써 주세요.

### 추천 2 (시의성 최고): 바뀐 구매법

- **상단 고정 제목:** 고디바 모찌, 이제 새벽 줄 안 서도 돼요
- **화면 중앙(0~2초):** 29일부터 바뀐 구매법 (일단 저장)
- **흐름:** 0~6초 예약제 정보(캐치테이블, 오전 10시, 하루 네 타임) → 6초 재훅 "근데 줄이 없어져도 이 떡은 계속 팔릴까요?" → 공식(익숙한 것 + 하나) → 다음 후보

| 항목 | 평가 | 근거 |
|---|---|---|
| 1~3초 멈춤 | O | 고디바를 사려던 사람에게 지금 바로 필요한 정보. "일단저장) 빠르게 사는 법"(90만, 10배) 패턴 |
| 화제 키워드 | O | 고디바 모찌 |
| 시의성 | O | 10/29 발표, 이틀 된 뉴스 |
| 계정 정체성 | △ | 앞 6초가 구매 가이드라 분석 계정 색이 약해짐. 6초 재훅이 반드시 필요 |
| 수명 | X | 정보형이라 1~2주면 낡음. **11월 첫 주 안에 올릴 수 있을 때만** 선택 |

### 추천 3 (보류 안): 기존 7번 원안

시간이 없으면 원안도 쓸 수 있어요. 다만 중앙 문구를 "다음에 줄 설 디저트, 공식이 있어요"로 두면 첫 화면에 사실이 없어서 1안보다 멈춤이 약해요.

## 3. "그다음은?"에 줄 수 있는 답 (어느 훅이든 필요)

"그다음은?"을 약속했으면 마지막에 **이름 하나**를 대야 해요. 보도에 나온 후보예요(검색 요약 기준, 대본 쓰기 전 원문 확인 필요).

| 후보 | 근거 | 공식("익숙한 것 + 하나")과 맞나 |
|---|---|---|
| 피자설기·피자절편 | 세계일보(10/25): "두쫀쿠·버터떡 다음은 '피자절편'", CU가 10/8 상시 판매 상품으로 출시 | O (떡 + 피자) |
| 편의점 고급 모찌 | 스트레이트뉴스(10/31): "다음 유행은 고디바 모찌? 편의점 신상 디저트 출시 경쟁 가속" | O (편의점이 고디바 조합을 따라옴) |
| 두바이 쫀득 찹쌀떡(CU) | 누적 약 280만 개 보도 | O (찹쌀떡 + 두쫀쿠) |
| 12격 초코 찹쌀떡 | 방향 문서 vidIQ 표: 10/19 250만 뷰(20배) | O |

수요 근거로는 "롯데백화점 최근 1년 모찌류 구매 건수 전년 대비 +103%"(보도)를 한 줄 넣으면 "유행이 아니라 흐름"이라는 설득력이 생겨요.

**추천 마무리:** "한정선은 생과일, 고디바는 초콜릿, 다음은 피자. 전부 익숙한 떡에 하나를 더했어요." 이름을 대되 단정하지 않게 "지금 뜨는 후보"로 보여 주기(방향 문서의 한계 문장 유지).
