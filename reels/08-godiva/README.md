# 08 고디바 모찌

60초 미만(59.9초). 7편 한정선 끝에 예고한 "고디바는 왜 새벽부터 줄을 설까"에 답하는 편이에요.

- 훅: "떡 하나에 8,500원 / 새벽 6시에 와도 4시간 반 대기"
- 답(이유 세 가지): ① 이미 아는 맛(검증된 찹쌀떡 + 초콜릿 하나, MAYA 법칙) ② 이미 있는 줄(한정선 줄에서 넘어온 사람들) ③ 딱 한 곳(매장이 하나라 줄이 새벽으로 당겨짐)
- 펀치라인: "사람들은 새로운 맛이 아니라, 아는 맛의 새 버전에 줄을 서요"
- 이전 편 문제 수정: 강조 표시를 글자 뒤 핑크 박스 대신 금색 밑줄로 바꿔 뒤 글자를 가리지 않게 했고, 내레이션은 줄마다 따로 생성해 받아쓰기로 깨짐을 검수했어요.
- BGM: "Crinoline Dreams" Kevin MacLeod (CC BY 4.0, 캡션에 크레딧 표기)

캡션 요약: "고디바 모찌, 왜 새벽부터 줄을 설까요? 🍫" (전문은 `caption.md`)
