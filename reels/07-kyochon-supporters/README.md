# 07 교촌치킨 서포터즈 사전미션

27초. 직접 녹화한 교촌치킨 앱 화면을 잘라 만든 '앱 포장 주문 10% 할인' 홍보 숏츠예요. 기업분석 계정용이 아니라 서포터즈 지원용이에요.

- 훅: "잠깐! 교촌 아직도 배달로 시켜? 8,600원 그냥 버리는 중"
- 흐름: 배달 vs 포장 비교 → STEP 1~5 주문 방법 → 퇴근길 포장 주문 유도
- 개인정보: 지도·매장 주소·거리 블러, 마이페이지·쿠폰 QR 화면 제외
- 소리: 효과음만 (BGM은 업로드 시 플랫폼 음원 추천)
