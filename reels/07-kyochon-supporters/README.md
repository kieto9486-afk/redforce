# 07 교촌치킨 서포터즈 사전미션

직접 녹화한 교촌치킨 앱 화면으로 만든 '앱 포장 주문 10% 할인' 홍보 숏츠예요. 기업분석 계정용이 아니라 서포터즈 지원용이에요.

- **최종본 v3** (37초): 문장 사이 여유를 넣어 화면을 천천히 보여 주고, 목소리는 원본 음색 그대로(음량만 맞춤)
- v2 (25초): 3D 모션그래픽 첫 버전. 목소리 보정이 강하고 전환이 빨랐어요.
- 훅: 첫 프레임부터 "교촌 치킨값 8,600원 아끼는 법" + "잠깐, 교촌 아직도 배달로 시켜?"
- 흐름: 3D 배달 vs 포장 비교 → STEP 1~5 주문 방법 → 퇴근길 포장 주문 유도
- 개인정보: 지도·매장 주소·거리 블러, 마이페이지·쿠폰 QR 화면 제외
- v1 (27초)은 자막만 있는 첫 초안이에요.
