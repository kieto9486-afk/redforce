# 신세계푸드 숏츠 대본 v2 (인과 흐름)

흐름: 현황 → 비교로 문제 확인 → 원인 → 그래서 SWOT → 그렇다면 누구에게 → 그래서 전략 → 그러면 결과

| 단계 | 내레이션 | 화면 |
|---|---|---|
| 인트로 | 대기업 분석, 여섯 단계면 끝납니다. 신세계푸드로 직접 따라 해볼게요. | 6단계 카드 + 신세계푸드 카드 |
| 01 자료수집 (현황) | 먼저 숫자부터 봅니다. 신세계푸드는 매출 1조 2천억 원인데, 이익률은 겨우 0.4%예요. | 매출·이익률 카운트업 |
| 02 비교 (문제 확인) | 이게 낮은 걸까요? 비교해 보면, SPC삼립 1.1%, CJ제일제당 4.6%. 확실히 낮습니다. | 막대 성장, "약 11배 차이" |
| 원인 | 왜일까요? 매출의 절반 가까이가 같은 그룹 회사와의 거래라, 마진을 높이기 어려운 구조예요. | 44% 도넛 |
| 03 SWOT | 그래서 그룹 판로는 안정적인 강점이면서, 낮은 이익률이라는 약점이 됩니다. 기회는 K-베이커리 수출, 위협은 원재료값이에요. | 강점→약점 화살표로 연결된 SWOT |
| 04 STP | 그렇다면 누구에게 팔아야 할까요? 그룹 밖 유통사와 해외 바이어. 스타벅스와 이마트가 검증한 빵 공장이라는 점이 무기입니다. | 과녁 위로 점 이동 + 포지션 도장 |
| 05 전략 | 그래서 전략은, 늘어난 빵 공장 물량을 그룹 밖과 해외로 파는 것. 자체 브랜드도 함께 키웁니다. | 전략 카드 슬라이드 |
| 06 예상결과 | 이렇게 베이커리에서 이익률 4%만 남겨도, 영업이익은 지금의 네 배가 넘습니다. | 48억 → 228억 막대, ×4.7 |
| 마무리 | 숫자, 비교, 원인, 그리고 방안과 결과. 이 흐름이면 어떤 기업도 분석할 수 있어요. 다음 기업은 댓글로 추천해 주세요. | 6단계 체크 + 댓글창 |
