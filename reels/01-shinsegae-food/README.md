# 01 신세계푸드

신세계푸드는 세 가지 결과물이 있어요. 최신 숏츠는 **c-6steps-shorts의 v2**예요.

## a. 노브랜드 버거 분석 리포트 (`a-nobrand-burger-report/`)
- 노브랜드 버거 vs 맘스터치·롯데리아·버거킹 비교 분석 HTML 리포트(`report.html`) + 표지 시안 3종(`covers/`)
- 결론: "가격은 이겼고, 점주가 버는 버거가 돼야 한다"
- 훅: 매출은 2.6배인데 영업이익은 18배 적음(48억 vs 897억)

## b. 회사 전체 분석 편 (`b-company-analysis/`)
- 신세계푸드 회사 전체 vs SPC삼립·CJ제일제당 비교, 80초 10장면
- `how_to_analyze_shinsegae_food.mp4`(무음) + `narration.srt`(내레이션 자막) + `storyboard.html`
- 표지 3종 중 **B안(스타벅스 케이크 만드는 회사 / 이익률 0.4%)** 선정 → `covers/cover_b.png`

## c. 6단계 분석 숏츠 (`c-6steps-shorts/`)
- 훅: "매출은 1조가 넘는데, 남는 건 0.4%. 이 회사, 어떻게 키울 수 있을까요?"
- 흐름: 자료수집 → 비교 → 원인 → SWOT → STP → 전략 → 예상 결과(이익률 4%면 영업이익 4배 이상)
- `shinsegae_food_6steps_shorts_v1.mp4` (59초, 첫 버전)
- `shinsegae_food_6steps_shorts_v2.mp4` (59초, 인과 흐름으로 다시 쓴 **최종**), 대본은 `script_v2.md`
