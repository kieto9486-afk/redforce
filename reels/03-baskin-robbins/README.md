# 03 배스킨라빈스 '왜 매달 새 맛을 낼까?'

'일상 궁금증 → 기업분석으로 답하기' 포맷의 첫 편. 60초.

- 훅: "한 번 온 손님을 단골로 만드는 공식, 딱 3가지"
- 흐름: 3초 퀴즈(31 = 한 달 31일) → 공식1 다시 올 이유 → 공식2 기간 한정(희소성 효과) → 공식3 메뉴판 해부(고정+교체, 협업) → 저장용 체크리스트 → 한 줄 정답
- 한 줄 정답: "새 맛이 파는 건 아이스크림이 아니라 '다음 방문'"
