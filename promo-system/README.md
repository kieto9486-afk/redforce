# F&B 경쟁사 프로모션 자동분석 시스템

교촌·BBQ·bhc·굽네치킨·푸라닭의 배달앱·자사앱 가격과 프로모션을 모아, 할인율을 자동 계산하고 비교·보고서까지 만드는 도구입니다.

## 흐름
데이터 수집 → 정제 → 가격·할인율 계산 → 경쟁사 비교 → AI 분석 → 보고서

## 폴더
- `data/promotions.csv` : 원본 데이터 (엑셀로 열고 고쳐도 됩니다)
- `src/calc.py` : 1단계 계산 프로그램
- `output/` : 계산 결과 (계산결과·채널가격차이·요약)
- `logs/` : 실행 기록, 오류 확인용

## 데이터 원칙
- `데이터구분`: **실제**(직접 캡처·공식 홈페이지·보도) / **가상**(기능 시험용). 화면과 보고서에서 항상 나눠 표시합니다.
- 모든 행에 `출처`와 `확인일`을 적습니다.
- 로그인이 필요한 정보, 확인되지 않은 정보는 넣지 않습니다.
- API 키는 코드에 넣지 않습니다 (실행 환경에서 자동 주입).

## 할인유형
없음 / 정액쿠폰(원) / 정률(%) / 가격인하(원) / 배달비할인(원) / 사이드증정

## 자동 계산 항목
메뉴할인액, 할인적용가, 할인율(%), 배달비할인액, 자사앱 대비 채널 가격 차이, 브랜드별 평균 할인액·할인율
조건이 불명확하면 `확인필요` 칸에 이유를 적습니다 (예: 종료일 불명확, 단품으로는 최소주문 미달, 중복 적용 불명확).

## 실행
```
python3 src/calc.py
```

## 내 컴퓨터에서 실행하기 (Windows/Mac)
1. Python 3.11 이상 설치 (python.org), 이 폴더를 내려받아 압축 풀기
2. 터미널에서 이 폴더로 이동 후: `pip install -r requirements.txt`
3. **대시보드 보기**: `streamlit run src/app.py` → 브라우저가 자동으로 열립니다 (AI 키 필요 없음)
4. AI 기능(캡처 읽기·보고서·변경 감지)을 쓰려면 제미나이 API 키를 환경변수로 설정합니다. 코드에는 키를 넣지 않습니다.
   - Windows: `setx GEMINI_API_KEY "내키"` / Mac: `export GEMINI_API_KEY="내키"`
5. 변경 감지(`monitor.py`)와 보고서 PDF는 Node.js와 Playwright가 추가로 필요합니다: `npm i playwright && npx playwright install chromium`

## 명령 모음
| 하는 일 | 명령 |
|---|---|
| 메뉴 캡처 → 표 | `python3 src/extract.py 쿠팡이츠 2026-11-15 data/captures/BBQ_20261115.png` |
| 쿠폰 캡처 → 표 | `python3 src/extract_coupon.py 쿠팡이츠 2026-11-15 bhc data/captures/bhc_쿠폰_20261115.png` |
| 확인 후 본표 반영 | `python3 src/approve.py` |
| 계산 | `python3 src/calc.py` |
| 대시보드 | `streamlit run src/app.py` |
| 보고서 | `python3 src/report.py` |
| 공식 이벤트 변경 감지 | `python3 src/monitor.py` |
